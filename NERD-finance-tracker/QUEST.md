# Personal Finance Tracker

## Why this task
This task introduces you to building a full-stack application with a focus on user data management, which you haven't tackled yet. It will also enhance your Python skills with a Flask backend and introduce basic financial concepts through practical application.

## Instructions
Build a Personal Finance Tracker that consists of a frontend and a backend. Structure it into the following modules:

1. **Backend (Flask)**:
   - Create a RESTful API to manage financial transactions (income and expenses).
   - Implement user authentication to allow users to register and log in (using Flask-Login).
   - Design a data model for transactions, with fields for amount, category, date, and user ID.
   - Handle errors gracefully (e.g., invalid data submissions, authentication failures).
   - Write unit tests for your API endpoints.

2. **Frontend (HTML/JavaScript)**:
   - Develop a simple user interface to input transactions and display a list of transactions.
   - Use Fetch API to make asynchronous requests to the backend.
   - Implement form validation to ensure correct data submission.
   - Display a summary of finances (total income, total expenses, balance).

3. **Data Persistence**:
   - Use a lightweight JSON file or an in-memory database (like SQLite) to store transaction data, allowing for easy setup and testing without complex database systems.

4. **Error Handling**: Ensure the application handles potential errors, such as network issues and invalid user input, with user-friendly messages.

5. **Testing**: Write basic tests for both the frontend and backend components to ensure the application works as expected.

## Add your own twist
Extend the application by adding charts that visualize the financial data over time, using a library like Chart.js, to provide users with insight into their spending habits.
