# Personal Finance Tracker with Budgeting Features

## Why this task
This project will push your skills into the realm of backend development and data management, which you haven't explored deeply yet, given your frontend and scripting background. You'll gain practical experience with API integration and data persistence.

## Instructions
Create a Personal Finance Tracker application that allows users to input their income and expenses, set budgets for categories, and visualize their financial health over time. Organize the project into three main modules: a frontend (using TypeScript and HTML/CSS), a backend (using Python with Flask), and a data storage layer (using JSON files). The frontend will consist of forms for inputting financial data, budget settings, and charts to visualize expenses. The backend will handle API requests for adding, retrieving, and deleting financial records, and will implement error handling for invalid data inputs and request failures. Ensure that the data layer properly saves and retrieves records in a structured format to allow easy access and manipulation.

## Add your own twist
Implement user authentication to allow multiple users to track their finances securely, along with a feature to export financial data to CSV format.
