Real-time Collaborative Text Editor
Why this task
This task pushes you into the realm of real-time collaboration, a feature set that goes beyond your existing experience in client-side JavaScript/TypeScript apps. It enhances your understanding of WebSocket communication and server-client architecture.
Instructions
Build a real-time collaborative text editor using WebSockets for communication between clients. Organize the project into layers: a front-end module for the UI (HTML, SCSS, JavaScript), a back-end module using Python's Flask or FastAPI, and a WebSocket handling module for real-time updates. Implement features like user sessions, basic text editing capabilities, and synchronization of text between users. Include error handling for connection issues and server errors. Ensure that edge cases, such as rapid edits and disconnects, are managed gracefully.
Add your own twist
Extend the functionality to support user authentication, allowing users to create accounts and manage their documents. Add version control for the documents, enabling users to revert to previous versions.
README (required)
In the repository, create a README.md file written in English, describing the project: what it is, how to run it, and what was used (languages, libraries, tools). This is a mandatory requirement for every quest.
Completion criteria

Implement a clean architecture with separate modules for front-end, back-end, and WebSocket handling.
Create a responsive UI for text editing using HTML and SCSS.
Utilize WebSocket for real-time communication between multiple users.
Implement error handling for network failures and server issues.
Write unit tests for individual modules and integration tests for end-to-end functionality.
Handle edge cases like user disconnections and rapid concurrent edits appropriately.
Document the API endpoints and the overall project structure clearly.
Ensure code is well-structured and follows best practices for maintainability.
The repository contains a README.md file written in English
