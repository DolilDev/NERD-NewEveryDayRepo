# Event Scheduler API with Notification System

## Why this task
This task introduces you to building a RESTful API with Node.js and Express, a stack you haven't used extensively yet. It combines backend logic with scheduling and notification features, pushing you beyond your existing comfort zone of front-end and simple scripts.

## Instructions
1. **Set Up the Project**: Initialize a Node.js project and install Express. Create a basic server setup with endpoints for adding, retrieving, updating, and deleting events.

2. **Define the Event Model**: Create a simple Event model with fields like title, description, date, and notification time. Use in-memory storage (like an array) for simplicity.

3. **Implement CRUD Operations**: Develop the following endpoints:
   - POST /events: Create a new event.
   - GET /events: Retrieve all events.
   - GET /events/:id: Retrieve a single event by ID.
   - PUT /events/:id: Update an existing event.
   - DELETE /events/:id: Delete an event.

4. **Notification System**: Implement basic logic to send notifications (console log for simplicity) a specified time before the event starts. Use `setTimeout` for scheduling notifications.

5. **Error Handling**: Ensure proper handling of common error scenarios, such as invalid input, event not found, and server errors. Return meaningful error responses.

6. **Basic Tests**: Write unit tests for your API endpoints using a testing framework like Jest or Mocha to verify that they behave as expected.

7. **Documentation**: Create a simple README file explaining how to set up and use your API, including API endpoints and example requests.
