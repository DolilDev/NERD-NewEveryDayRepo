# Personal Finance Tracker App

## Why this task

## Instructions
Create a Personal Finance Tracker App that allows users to manage their income and expenses. The project will be structured in multiple layers: 

1. **Backend (Node.js + Express)**: 
   - Set up an Express server. 
   - Implement RESTful APIs for creating, reading, updating, and deleting transactions. 
   - Use in-memory storage (like an array) for quick data handling, avoiding external databases. 
   - Include error handling for all API endpoints (e.g., validation errors, empty requests). 
   
2. **Frontend (Svelte)**: 
   - Build the user interface using Svelte, focusing on a clean and responsive design. 
   - Create components for listing transactions, adding new transactions, and viewing summaries. 
   - Implement state management for tracking user inputs and fetched data. 
   - Ensure proper error messages are displayed to the user, e.g., if a transaction fails to save. 
   
3. **Integration**: 
   - Connect the frontend to the backend using fetch API calls. 
   - Ensure all endpoints are consumed correctly and handle errors gracefully on the frontend. 
   
4. **Testing**: 
   - Write unit tests for backend API endpoints using a framework like Jest. 
   - Implement basic end-to-end tests to ensure the frontend components function correctly with the backend. 
   
5. **Documentation**: 
   - Document the API endpoints, including request and response examples. 
   - Write a short README explaining how to set up and run the application locally.

## Add your own twist
