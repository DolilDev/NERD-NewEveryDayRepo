# Personal Finance Tracker with Data Visualization

## Why this task
You have a solid background in web technologies but lack experience with backend data processing and visualization. This task will bridge that gap by incorporating Python for data handling, TypeScript for the frontend, and a visualization library to create insightful graphs.

## Instructions
Create a personal finance tracker that allows users to input expenses and income, categorize them, and visualize their financial data. The project should be organized into the following modules:

1. **Backend (Python)**:
   - Set up a simple API using Flask that handles CRUD operations for financial records.
   - Implement data validation to ensure entries are numeric and within reasonable limits.
   - Store data in-memory for simplicity (a dictionary) but structure it for potential future database integration.

2. **Frontend (TypeScript + HTML/SCSS)**:
   - Create a form for users to input income and expenses, with dropdowns for categorization.
   - Display a list of entered transactions, showing date, amount, and category.
   - Implement error handling to show user-friendly messages for invalid entries.

3. **Data Visualization**:
   - Utilize a lightweight charting library (like Chart.js or D3.js) to visualize income versus expenses over time.
   - Create a dashboard view displaying these charts, updating dynamically as transactions are added.

4. **Testing**:
   - Write unit tests for the backend API methods and integration tests for the data flow.
   - Implement basic front-end tests using a tool like Jest or Cypress to ensure forms behave as expected.

5. **Error Handling**:
   - Handle edge cases such as negative amounts, non-numeric entries, and network errors during API calls.

## Add your own twist
Extend the application to include a user authentication system using Flask-Login, allowing multiple users to save their financial data securely. Additionally, implement data export features to CSV or JSON for users to download their financial records.
