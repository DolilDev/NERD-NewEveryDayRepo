# Personal Finance Tracker Web App

## Why this task
This task introduces the user to the domain of personal finance management, which they haven't tackled yet, and combines both frontend and backend development in a cohesive web application using JavaScript and TypeScript.

## Instructions
Build a personal finance tracker web application that allows users to manage their expenses and incomes. The project should be divided into the following modules:

1. **Frontend Module**: Use HTML, CSS, and JavaScript/TypeScript to create the user interface.
   - Create a dashboard displaying total income, total expenses, and a balance.
   - Enable users to add, edit, and delete income and expense records.
   - Implement form validation for input fields (e.g., amount should be positive).

2. **Backend Module**: Use a lightweight server framework (like Express.js) to handle API requests.
   - Create RESTful API endpoints for CRUD operations on financial records (add, retrieve, update, delete).
   - Implement error handling for invalid requests and server errors.

3. **Data Storage Module**: Store financial records in memory (using a simple in-memory object) for persistence during the session.
   - Ensure that data is retained as long as the server is running.
   - Handle potential data loss and implement a way to reset data if needed.

4. **Error Handling**: Incorporate proper error handling in both frontend and backend code. Display user-friendly error messages in the UI.
   - Handle cases where network requests fail and provide feedback to the user.

5. **Testing Module**: Write unit tests for key functions in both frontend and backend.
   - Use a testing library such as Jest for JavaScript/TypeScript testing.
   - Ensure that all major functionalities are covered by tests.

6. **Documentation**: Create a README file that provides instructions for setting up and running the application.
