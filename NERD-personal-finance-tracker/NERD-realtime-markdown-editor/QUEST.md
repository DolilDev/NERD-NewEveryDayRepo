## Why this task

## Instructions
Build a real-time collaborative Markdown editor using TypeScript for the frontend and Python for a lightweight backend. Split the project into the following modules:

1. **Frontend (TypeScript)**:
   - Create a simple web interface with a text area for Markdown input and a preview pane.
   - Implement web socket communication using a library like Socket.IO to handle real-time updates.
   - Ensure that the editor can handle multiple users, updating the Markdown preview in real time as users type.
   - Handle basic error scenarios such as connection loss, providing user feedback.

2. **Backend (Python)**:
   - Use Flask or FastAPI to set up a lightweight server that manages web socket connections.
   - Create an API endpoint to serve the initial HTML/JS client.
   - Implement logic to broadcast messages to all connected clients whenever a user types in the editor, managing state for each active session.
   - Handle edge cases such as users disconnecting and reconnecting without losing their state.

3. **Testing and Error Handling**:
   - Write unit tests for both frontend and backend to ensure proper functionality.
   - Implement error handling for common issues such as failed connections or malformed input.

4. **Documentation**:
   - Provide README documentation with setup instructions, usage examples, and how to run tests.
